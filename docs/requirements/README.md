# Requirements & Specifications

This directory contains feature specifications, functional requirements, and user stories for the 5 feature modules:

1. **Authentication & Authorization (`feature/auth`)**: Role-based access control (Admin, Student, Company), JWT handling, registration, password reset.
2. **Student Management (`feature/student`)**: Student profile, resume upload, academic records, application status tracking.
3. **Company & Placement Drive Management (`feature/company-drive`)**: Company registration, drive posting, eligibility criteria, CTC details.
4. **Application & Interview Scheduling (`feature/application-interview`)**: Drive applications, shortlisting, interview round scheduling, offer management.
5. **Admin Dashboard & Analytics (`feature/admin`)**: User approvals, system reporting, placement statistics, placement drive overrides.
